# Owerri Life MVP

React + TypeScript + Vite browser prototype for an Owerri/Imo State life simulation.

## Run
npm install
npm run dev

Features: interactive Owerri map, locations, jobs, money, energy, happiness, reputation, food, socializing and day progression.

The map is a game-design representation, not a GPS/survey map. Verify real-world locations before public release.
